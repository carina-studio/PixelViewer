# PixelViewer 2026.2 中有什么改变
 ---

## 新功能
+ 新增 `YUV420 (8 位，MIPI)`、`YUV420 (旧版 8 位，MIPI)`、`YUV420 (10 位，MIPI)`、`YUV422 (10 位，MIPI)`、`Bayer 排列 (10 位，紧密排列)`、`Bayer 排列 (12 位，紧密排列)` 和 `Bayer 排列 (14 位，紧密排列)` 格式。
+ 支持指定图像各边的向内裁剪。
+ 支持 RGB 和 ARGB 格式的色彩预先校正。
+ 新增色温和色调调整。
+ 新增自动亮度调整。
+ 支持暂时显示未应用滤镜的图像。
+ 新增 `ProPhoto RGB` 色彩空间。
+ 在状态栏显示图像的颜色深度。

## 优化
+ 优化整体用户界面的性能。
+ 重新设计绘制参数面板。
+ 将亮度和颜色调整移至新增的滤镜面板。
+ 优化滤镜参数调整的使用体验。
+ 优化 macOS 上全屏模式的使用体验。
+ 保存最近打开和保存图像所在的文件夹路径。
+ 优化设置色彩预先校正的使用体验。
+ 优化色彩预先校正的准确度。
+ 优化应用亮度、对比、亮部和暗部调整的质量。
+ 优化自然饱和度调整的强度和对肤色的保护。
+ 自动颜色调整改为调整色温、色调和自然饱和度。

## 行为变更
+ 由图像文件（例如 DNG）定义的色彩预先校正在打开其他文件后不再保留。
+ 打开文件或选择不支持色彩预先校正的格式时，将重新应用当前配置的色彩预先校正。
+ 当使用来自文件的配置时，不再提供自动评估图像尺寸。
+ 移除亮度和对比调整函数的选项。

## 错误修复
+ 修复色彩预先校正的微小变更被忽略的问题。
+ 修复色域绘制超出 xy 色度表范围的问题。
+ 修复 macOS 上更改语言后菜单栏未更新的问题。
+ 其他错误修复。
