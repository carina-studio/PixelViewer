# PixelViewer 2026 中有什么改变
 ---

## 新功能
+ 支持以可调整的帧率连续播放帧。
+ 支持将多个文件作为单一帧序列打开。
+ 支持使用键盘快捷键关闭应用程序 (Windows/Linux 上为 `Ctrl+Q`，macOS 上为 `⌘Q`)。
+ 支持打开 TIFF 图像。
+ 支持将图像保存为 TIFF。
+ 支持显示或隐藏色阶分布图上的平均值标记。

## 优化
+ 支持解析并应用 DNG 图像中记录的白平衡。
+ 支持解析并应用 DNG 图像中记录的色彩矩阵。
+ 支持解析并应用 DNG 图像中记录的线性化对照表。
+ 支持指定 `ABGR_16161616`、`ARGB_16161616`、`BGRA_16161616` 与 `RGBA_16161616` 格式图像的有效位数。
+ 提升去马赛克的性能。
+ 提升保存 PNG 格式图像的性能。
+ 支持在绘制下一张图像的同时保存已绘制的图像。
+ 支持调整色阶分布图面板的宽度。
+ 新配置的名称默认包含相机名称。
+ 当变更 `语言` 选项而改变中文环境后不再需要重启应用程序。
+ 避免当已绘制图像的内存使用量达到上限时清除正在显示的图像。

## 行为变更
+ 当绘制图像时应用了颜色对照表（例如包含线性化对照表的 DNG 图像），将无法指定图层的有效位数。

## 错误修复
+ 修复部分 RGB/ARGB 格式（例如 `BGRA_8888`、`RGB_565`）的图像所选像素颜色数值范围显示错误的问题。
+ 修复当无法根据文件名称判断格式时（例如扩展名错误的文件），未能正确识别图像文件格式的问题。
+ 修复部分 DNG 图像因未正确读取黑色值，导致对比度过低的问题。
+ 修复 `GBRG (4x4)` Bayer 排列方式的 DNG 图像颜色不正确的问题。
+ 修复部分 ICC 色彩配置文件加载失败，导致某些广色域显示器的屏幕色彩空间被错误检测为 `sRGB` 的问题。
+ 修复使用 `BT.601 (525 行，SDTV)` 或 `BT.601 (625 行，SDTV)` 色彩空间的图像因白点错误导致颜色不正确的问题。
+ 修复部分色彩空间（例如 `BT.2100 (HLG 转换，HDR-TV)` 与 `BT.2100 (PQ 转换，HDR-TV)`）的图像在保存为 JPEG 或 PNG 时色彩空间编码错误，以及重新打开时解码错误的问题。
+ 修复无法将 `Noto Sans` 应用至中文环境的问题。
+ 修复在当前绘制尚未完成时再次请求绘制，导致没有绘制出图像的问题。
+ 修复保存配置后`视为线性色彩空间`选项被自动关闭的问题。
+ 其他错误修复。
