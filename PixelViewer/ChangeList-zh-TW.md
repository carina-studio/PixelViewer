# PixelViewer 2026 中有什麼改變
 ---

## 新功能
+ 支援以可調整的畫格速率連續播放畫格。
+ 支援將多個檔案作為單一畫格序列開啟。
+ 支援使用鍵盤快速鍵關閉應用程式 (Windows/Linux 上為 `Ctrl+Q`，macOS 上為 `⌘Q`)。
+ 支援開啟 TIFF 影像。
+ 支援將影像儲存為 TIFF。
+ 支援顯示或隱藏色階分布圖上的平均值標記。

## 改善
+ 支援解析並套用 DNG 影像中記錄的白平衡。
+ 支援解析並套用 DNG 影像中記錄的色彩矩陣。
+ 支援解析並套用 DNG 影像中記錄的線性化對照表。
+ 支援指定 `ABGR_16161616`、`ARGB_16161616`、`BGRA_16161616` 與 `RGBA_16161616` 格式影像的有效位元數。
+ 提升去馬賽克的效能。
+ 提升儲存 PNG 格式影像的效能。
+ 支援在繪製下一張影像的同時儲存已繪製的影像。
+ 支援調整色階分布圖面板的寬度。
+ 新組態的名稱預設包含相機名稱。
+ 當變更 `語言` 選項而改變中文環境後不再需要重新啟動應用程式。
+ 避免當已繪製影像的記憶體使用量達到上限時清除正在顯示的影像。

## 行為變更
+ 當繪製影像時套用了色彩對照表（例如包含線性化對照表的 DNG 影像），將無法指定圖層的有效位元數。

## 錯誤修正
+ 修正部分 RGB/ARGB 格式（例如 `BGRA_8888`、`RGB_565`）的影像之選取像素顏色數值範圍顯示錯誤的問題。
+ 修正當無法根據檔案名稱判斷格式時（例如副檔名錯誤的檔案），未能正確辨識影像檔案格式的問題。
+ 修正部分 DNG 影像因未正確讀取黑色值，導致對比度過低的問題。
+ 修正 `GBRG (4x4)` Bayer 排列方式的 DNG 影像顏色不正確的問題。
+ 修正部分 ICC 色彩描述檔載入失敗，導致某些廣色域顯示器的螢幕色彩空間被錯誤辨識為 `sRGB` 的問題。
+ 修正使用 `BT.601 (525 行，SDTV)` 或 `BT.601 (625 行，SDTV)` 色彩空間的影像因白點錯誤導致顏色不正確的問題。
+ 修正部分色彩空間（例如 `BT.2100 (HLG 轉換，HDR-TV)` 與 `BT.2100 (PQ 轉換，HDR-TV)`）的影像在儲存為 JPEG 或 PNG 時色彩空間編碼錯誤，以及重新開啟時解碼錯誤的問題。
+ 修正無法將 `Noto Sans` 套用至中文環境的問題。
+ 修正在目前的繪製尚未完成時再次要求繪製，導致沒有繪製出影像的問題。
+ 修正儲存組態後`視為線性色彩空間`選項被自動關閉的問題。
+ 其他錯誤修正。
