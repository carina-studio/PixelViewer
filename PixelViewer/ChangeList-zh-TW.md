# PixelViewer 2026 中有什麼改變
 ---

## 新功能
+ 支援使用鍵盤快速鍵關閉應用程式 (Windows/Linux 上為 `Ctrl+Q`，macOS 上為 `⌘Q`)。
+ 支援開啟 TIFF 影像。
+ 支援將影像儲存為 TIFF。
+ 支援顯示或隱藏色階分布圖上的平均值標記。

## 改善
+ 支援指定 `ABGR_16161616`、`ARGB_16161616`、`BGRA_16161616` 與 `RGBA_16161616` 格式影像的有效位元數。
+ 提升儲存 PNG 格式影像的效能。
+ 支援調整色階分布圖面板的寬度。

## 錯誤修正
+ 修正部分 RGB/ARGB 格式（例如 `BGRA_8888`、`RGB_565`）的影像之選取像素顏色數值範圍顯示錯誤的問題。
+ 修正當無法根據檔案名稱判斷格式時（例如副檔名錯誤的檔案），未能正確辨識影像檔案格式的問題。
+ 修正部分 ICC 色彩描述檔載入失敗，導致某些廣色域顯示器的螢幕色彩空間被錯誤辨識為 sRGB 的問題。
+ 修正使用 `BT.601 (525 行，SDTV)` 或 `BT.601 (625 行，SDTV)` 色彩空間的影像因白點錯誤導致顏色不正確的問題。
+ 其他錯誤修正。
