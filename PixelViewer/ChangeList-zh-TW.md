# PixelViewer 2026 中有什麼改變
 ---

## 新功能
+ 支援於觸控螢幕及觸控板上以雙指縮放影像。
+ 支援水平和垂直翻轉影像。
+ 新增 `ARGB 色彩格式` 設定，可將選取像素色彩顯示為 `依來源影像位元深度` (最高 16 位元/色彩通道)、`8 位元 (0-255)` 或 `正規化 [0.0, 1.0]`。
+ 支援在 Windows 及 macOS 上套用系統文字大小至特定使用者介面元素。
+ 支援從現有的 PixelViewer 應用程式匯入資料。

## 改善
+ 改善影像檢視器的使用者體驗。
+ 改善對 `EXIF`/`TIFF` 方向中繼資料的讀取，可正確處理所有方向值（包含編碼翻轉的值）。
+ 當來源影像不包含 Alpha 通道時，選取像素色彩會顯示為 `RGB(...)` 而不是 `ARGB(...)`。

## 行為變更
+ 點兩下影像時於 `調整至視窗大小` 與 `縮放至 100%` 之間切換。
+ 在 Windows 上當應用程式未關閉時重啟系統，應用程式將在開機後自動啟動。
+ 不再支援 `使用緊密版面配置` 選項。
+ 當變更 `語言` 選項而改變中文環境後需要重新啟動應用程式。
